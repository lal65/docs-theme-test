## Summary
The Views module adds a series of custom row and style plugins that integrate
parts of the World Campus Design System into Views. This allows for a very
off-the-shelf views building experience. Views fields are able to be mapped to
the various properties of the design system components.

## Row plugin: Basic tile
The basic tile row plugin has 3 configurable options: the primary label, 
secondary label, and background color. The primary and secondary labels are
mapped from views fields and the background color has two options: default and
light.

This plugin displays records via the
[Basic Tile](https://psu-online-education.github.io/?p=viewall-molecules-basic-tile)
design system component.

## Row plugin: Navigation tile
The navigation tile row plugin has three configurable options: the label, a
description, and a toggle for enabling a chevron icon. The label and
description are mapped from views fields and the chevron toggle is a checkbox.

This plugin displays records via the
[Navigation Tile](https://psu-online-education.github.io/?p=viewall-organisms-navigation-tile)
design system component.

## Style plugin: Multi-column
The multi-column style plugin has two configurable options: the number of
columns and the gap size between them. The column options are 2, 3, or 4. The
gap options are default and large.

This plugin displays rows via one of the
[Two column](https://psu-online-education.github.io/?p=viewall-layouts-two-col),
[Three column](https://psu-online-education.github.io/?p=viewall-layouts-three-col),
or
[Four column](https://psu-online-education.github.io/?p=viewall-layouts-four-col)
design system components.

## Style plugin: Grid
The grid style plugin has one configurable option: the number of columns. The
column options are 1, 2, 3, and 4.

This plugin displays rows via the
[Grid](https://psu-online-education.github.io/?p=viewall-molecules-grid)
design system component.

## Requirements
This module requires no modules outside drupal core.

## Installation
Install as you would normally install a contributed Drupal module. For further
information, see
[Installing Drupal Modules](https://www.drupal.org/extending-drupal/installing-drupal-modules).

## Configuration
This module does not expose any configuration.
