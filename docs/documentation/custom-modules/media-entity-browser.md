## Summary
This module was originally written to bridge a gap in the contributed
[Media Entity Browser](https://www.drupal.org/project/media_entity_browser)
module. Because this application was developed before core media WYSIWYG
support existed, it is still in limited use.

## Custom Media Selection Views
This module attaches various libraries to a series of custom views that were
originally set up to provide embedding support for images, PDF brochures, and
remote oEmbed videos.

### Technical debt
This module should eventually be eliminated, replaced with the core media
library feature in the WYSIWYG.

## Requirements
This module requires the contributed
[Media Entity Browser](https://www.drupal.org/project/media_entity_browser)
module.

## Installation
Install as you would normally install a contributed Drupal module. For further
information, see
[Installing Drupal Modules](https://www.drupal.org/extending-drupal/installing-drupal-modules).

## Configuration
This module does not expose any configuration.
