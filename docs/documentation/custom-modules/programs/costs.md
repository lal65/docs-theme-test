## Summary
This submodule specializes in features related to program tuition and costs.

## Tuition estimator tool
The tuition estimator tool is a form and block combination that allows
prospective students to choose a graduate level program and jump directly to
the costs section within that program.

## Technical debt
This custom block and form should be replaced with a no-code webform.

## Requirements
This module requires the custom Programs module.

## Installation
Install as you would normally install a contributed Drupal module. For further
information, see
[Installing Drupal Modules](https://www.drupal.org/extending-drupal/installing-drupal-modules).

## Configuration
This module does not expose any configuration.
